# Mission — Claymorphism Design System
Source: [UI UX Pro Max / Claymorphism catalog](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/a4fc248f6136552cb881e298847abc7ddce84e6b/.claude/skills/ui-ux-pro-max/data/styles.csv), style ID claymorphism. [Skill workflow](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/a4fc248f6136552cb881e298847abc7ddce84e6b/.claude/skills/ui-ux-pro-max/SKILL.md). Exact catalog row and guidance were reviewed directly; the upstream Python generator was not run (repository download is unavailable in the authoring environment).
## Direction
Soft 3D / clay surfaces, pastel lilac/mint/blue/peach, rounded 16–24px corners, thick 3px light borders, inner and outer shadows, 200ms pressed feedback. The catalog warns against using toy-like treatments in data-critical professional UIs; adapt the aesthetic to a developer dashboard by limiting decorative effects to login illustration and surface hierarchy. Use readable dark text and explicit text for priority/state. No gradients that obscure values, no animated chart/data or floating dashboard cards.
## Tokens
CSS variables in docs/style.css are canonical. Light mode only: ground #f4effa, surface #fffcff, ink #31263f, muted #5d526b, deep #584078, mint #d4f0df, blue #dcebf9, lilac #e9defa, peach #f9ded2. Use semantic accent inks for icons and tags, never color alone. System font with Thai fallback; no external fonts or CDN. Recessed inputs; raised cards and buttons; pressed feedback; no layout-changing animation. Focus ring and reduced-motion override.
## Layout
Login: two-column hero with a CSS clay illustration and isolated PAT card; single column on phones. Dashboard: floating left navigation, compact toolbar, four color-coded metrics, asymmetric bento for timeline and priority, full-width repo portfolio. Use two metrics per row on smaller screens, one on very narrow screens; stack panels and allow labels/IDs to wrap. Repository dialog: native dialog with clear selection count and keyboard focus.
## Security and regression
Retain all existing IDs, textContent rendering, local SVG icons, exact CSP, memory-only PAT and GitHub API GET-only. No external runtime dependencies. No simulated dashboard data in production. Test 375/768/1024/1440 widths, keyboard and reduced motion, contrast, login and picker with mock API. Real PAT and deployment require user verification.
