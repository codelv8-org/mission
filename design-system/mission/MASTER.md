# Mission — Intelligent Workspace / Modern Analytical Bento

## Direction
Selected by the user after testing claymorphism, liquid glass and neo-brutalism. Combine Swiss Modernism 2.0, Linear-inspired minimalist developer workspace, Data-Dense Dashboard and adaptive 12-column Bento Grid. Source: [UI UX Pro Max style catalog](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/a4fc248f6136552cb881e298847abc7ddce84e6b/.claude/skills/ui-ux-pro-max/data/styles.csv), IDs minimalism-and-swiss-style, swiss-modernism-2-0, data-dense-dashboard and bento-box-grid. The catalog recommends dense grids for analytics and warns about relying on Bento for dense tables; combine compact cards with native scrollable tables. Applied the reviewed catalog directly, not the unavailable Python generator.

## Design tokens
Canonical tokens live in docs/style.css. Light canvas #F4F5F8, surface #FFFFFF, ink #20232C, muted #596579, accent #6366F1. Dark canvas #111318, surface #1B1E25, ink #F1F3F7, muted #A7B0BF, accent #9295FF. Primary button uses separate accessible foreground/background tokens. Semantic green, amber, red, violet tints for status; heatmap uses indigo levels with explicit counts, question marks for unavailable data. Cards 14px radius, 1px neutral border, minimal elevation, 8px spacing scale, 160ms feedback, no heavy shadows/gradients. System/Light/Dark selector on login and workspace synchronized for the session; system changes followed when selected. Native dialog, all chart, form and status colors use theme tokens. LINE Seed Sans TH preferred via local installed font name, Segoe UI/system/Tahoma fallback. Binary font retrieval unavailable; no remote CDN or bundled WOFF2 added. No changes to CSP.

## Layout and behavior
Flat attached left navigation and thin toolbar; compact app shell. 3 KPI cards, timeline 7/12 and activity 5/12 on wide desktop, 4 lower analytics cards at 1440+, then 2 or 1 responsive columns. Native table scrolling and sticky headers retained; compact desktop targets with 44px touch targets. Six analytic cards expand inline to full grid width (one at a time), accessible controls and reset on session/data reset. Real daily sparklines for active-project counts and observed events from the same loaded snapshot and selected period/repository scope, independent of the event-type filter; no issue-history sparkline because only a current snapshot exists. Existing tooltips/drill-down and partial-data semantics preserved. No invented trends or percentage deltas.

## Verification
GitHub PAT, API permissions, API client, analytics model and CSP unchanged. No backend, network dependencies or extra API requests. Theme choice in session memory only. Regression tests cover static contracts, sampled text contrast in both themes, actual browser layout, theme switch, system preference, expand/collapse, chart render, filter, day drill-down, repository dialog and logout using synthetic fixture. Production login needs real credential testing by the user.

## Download HTML snapshot
Toolbar secondary action enabled only with a completed loaded snapshot. Explicit confirmation warns of unencrypted private project information. Static HTML preserves current active view, filters, theme, rendered chart SVG, selected-day detail, and full scrollable rows, with timestamps and read-only labeling. No hidden views, raw payload, PAT, login or refresh controls; CSSOM embeds local styles, no network requests. Native details can expand/collapse and GitHub links remain external references. Snapshot does not update or provide offline data storage.

## Calendar periods
Asia/Bangkok (ICT) calendar boundaries; date series anchored to the last successful load. Last Month: first of previous month through today, daily; Last Year: January 1 of previous year through today, monthly. Daily column date + Thai weekday, weekends tinted independently of heat levels; month groups span exact day counts using colspan and colgroup, sticky row headers, no grouped row in monthly mode. Daily/monthly chart, sparklines, event drill-down and export share the period. Extended loads have explicit bounded pagination and partial states, not complete audit histories. Current open-issue snapshot does not change with time filters.
